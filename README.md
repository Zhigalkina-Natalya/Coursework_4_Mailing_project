# Проект 4. Сервис управления рассылками

Учебный проект по разработке веб-приложений на Django с рассылкой сообщений.

Создан с использованием **Django** и **Bootstrap**.

## Задачи проекта

CRUD для получателей, сообщений, рассылок; ручная / консольная отправка;
роли (пользователь, менеджер), подтверждение email, кеширование Redis.

---

## Структура

- `config/` - настройки проекта
- `mailing/` - приложение рассылок
- `users/` - приложение пользователей
- `manage.py` - Django management

---

## Установка и настройка

1. Установите зависимости проекта

```
poetry install
```

или, если вы используете pip:

```
pip install -r requirements.txt
```

2. Настройте базу данных PostgreSQL

```
Убедитесь, что у вас установлен и запущен сервер PostgreSQL.
```

3. Создать `.env` по образцу: `.env.sample`


4. Применить миграции:

```
python manage.py migrate
```

5. Создать суперпользователя:

```
python manage.py createsuperuser
```

или

```
python manage.py createadmin
```

6. Создать группу «Менеджеры» и назначить права:

```
python manage.py create_manager_group
```

7. Запустить сервер:

```
python manage.py runserver
```

8. Использование:

- Интерфейс: http://127.0.0.1:8000/
- Админ: http://127.0.0.1:8000/admin/
- Отправка рассылки из консоли:

```
python manage.py send_mailing <mailing_id>
Например, python manage.py send_mailing 3
```

## Роли пользователей

### Обычный пользователь
- Регистрируется через форму.
- Подтверждает email (через письмо).
- Может создавать и редактировать **только свои** сообщения, рассылки и получателей.

### Менеджер
- Назначается администратором в группе **«Менеджеры»**.
- Может просматривать все рассылки, сообщения и получателей.
- Может **включать/отключать рассылки** (`can_disable_mailings`).
- Не может редактировать или удалять чужие данные.

### Администратор
- Имеет полный доступ (CRUD + управление пользователями).
- Может блокировать / разблокировать пользователей.
---

## Основной функционал

- Регистрация и активация пользователей по email.
- Авторизация и выход из системы.
- CRUD для:
  - Получателей (`Recipient`)
  - Сообщений (`Message`)
  - Рассылок (`Mailing`)
- Ручной запуск рассылки из интерфейса и через консоль.
- Автоматическая запись попыток отправки (`MailAttempt`).
- Кеширование данных через Redis.
- Разграничение прав пользователей и менеджеров.
- Отображение статистики рассылок на главной странице.

## Проверка проекта

1. Зарегистрируйте нового пользователя и подтвердите email.
2. Авторизуйтесь и создайте получателя, сообщение, рассылку.
3. Перейдите в админку → добавьте пользователя в группу «Менеджеры».
4. Проверьте:
   - Менеджер видит все рассылки, но не может редактировать чужие.
   - Менеджер может включать/отключать рассылки.
   - Менеджер не может блокировать администратора.
5. Отправьте рассылку вручную: `python manage.py send_mailing <id>`
или через интерфейс («Отправить сейчас»).
6. Убедитесь, что попытки отправки фиксируются в модели `MailAttempt`.
